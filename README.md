# CNC4ME

Support and privacy pages for CNC4ME, the iPhone and iPad app that writes and checks G-code for the school shop's milling machine.

- Support: https://ricky-zombie.github.io/cnc4me/
- Privacy policy: https://ricky-zombie.github.io/cnc4me/privacy.html
- Report a problem: [Issues](https://github.com/ricky-zombie/cnc4me/issues)

The app's source is not in this repository.
